# TOPIC 1: Computer Fundamentals
**Topic ID:** JSS-DGT-001-01

## 1.1 Definition of a Computer

A **computer** is an electronic device that accepts data (input), processes it according to a set of instructions (a program), and produces a result (output), which it can store for future use.

**Four core operations:**
1. **Input** — Receiving data from the user or environment
2. **Processing** — Manipulating data according to instructions
3. **Output** — Presenting results to the user
4. **Storage** — Saving data and programs for later use

---

## 1.2 Types of Computers

| Type | Description | Examples |
|------|-------------|---------|
| **Microcomputer** | Small; for personal use | Desktop PC, laptop, tablet |
| **Minicomputer** | Medium-sized; shared by multiple users | Server in a school |
| **Mainframe** | Very large; handles millions of transactions | Bank servers |
| **Supercomputer** | Most powerful; scientific calculations | Weather forecasting, nuclear research |

---

## 1.3 Hardware — Input, Output, and Storage

### Input Devices:
| Device | Function |
|--------|---------|
| **Keyboard** | Enter text and commands |
| **Mouse** | Point and click to control cursor |
| **Scanner** | Convert physical documents to digital |
| **Webcam** | Capture video/photos |
| **Microphone** | Input audio |
| **Touchscreen** | Input by touching the screen |
| **Joystick** | Gaming and some industrial uses |

### Output Devices:
| Device | Function |
|--------|---------|
| **Monitor (screen)** | Display visual output |
| **Printer** | Produce hard copies |
| **Speaker** | Produce audio output |
| **Projector** | Display on large screen |
| **Headphones** | Personal audio output |

### Storage Devices:
| Device | Type | Capacity range |
|--------|------|---------------|
| Hard Disk Drive (HDD) | Internal/External | 500 GB – 10 TB |
| Solid State Drive (SSD) | Internal | 128 GB – 4 TB |
| USB Flash Drive | Portable | 4 GB – 512 GB |
| CD/DVD | Optical | 700 MB / 4.7 GB |
| Memory card | Portable | 2 GB – 512 GB |
| Cloud storage | Online | Unlimited (subscription) |

---

## 1.4 The Central Processing Unit (CPU)

The **CPU** is the "brain" of the computer. It performs all calculations and instructions.

| Component | Function |
|-----------|---------|
| **Arithmetic and Logic Unit (ALU)** | Performs mathematical and logical operations |
| **Control Unit (CU)** | Directs the flow of data; coordinates all components |
| **Registers** | Tiny, very fast memory locations inside CPU |
| **Cache** | Fast memory close to CPU for frequently used data |

**CPU speed** is measured in GHz (gigahertz) — higher = faster.

---

## 1.5 Memory

| Type | Full name | Volatile? | Use |
|------|-----------|----------|-----|
| **RAM** | Random Access Memory | Yes (data lost when power off) | Working memory; runs open programs |
| **ROM** | Read Only Memory | No (data permanent) | Stores boot instructions (BIOS) |

---

## ✏️ Worked Examples

**Example 1 (BECE type):** Name TWO input devices, TWO output devices, and ONE storage device for a computer.

**Solution:**
**Input devices:**
1. Keyboard — used to type letters, numbers, and commands into the computer
2. Mouse — used to move the cursor on screen and select items by clicking

**Output devices:**
1. Monitor — displays text, images, and video as visual output
2. Printer — produces a physical (hard copy) printed version of a document

**Storage device:**
USB flash drive — a portable device that stores files and can be connected to different computers via USB port

---

## 🏆 Exam Focus

> **BECE** tests input vs output vs storage device classification, CPU components, and types of memory (RAM vs ROM).

> **Common trap:** A printer is an OUTPUT device (it gives you results). A scanner is an INPUT device (it puts data INTO the computer). A flash drive is a STORAGE device. Know all three categories clearly.

# TOPIC 2: Internet and Email
**Topic ID:** JSS-DGT-002-01

## 2.1 The Internet

**Definition:** The **internet** is a global network of millions of interconnected computers and devices that communicate using standardised protocols (mainly TCP/IP).

**The World Wide Web (WWW)** is a system of interconnected web pages (websites) accessed via the internet through a web browser. The internet is the infrastructure; the Web is a service that runs on it.

---

## 2.2 Key Internet Concepts

| Concept | Definition |
|---------|-----------|
| **Website** | A collection of web pages on a specific topic, hosted on a server |
| **URL** (Uniform Resource Locator) | The web address of a page (e.g., www.edupal.ng) |
| **HTTP/HTTPS** | Protocol for transferring web pages; S = Secure (encrypted) |
| **Browser** | Software to access websites (Chrome, Firefox, Safari, Edge) |
| **Search engine** | Helps you find websites (Google, Bing, Yahoo) |
| **ISP** (Internet Service Provider) | Company that provides internet access (MTN, Airtel, Glo) |
| **IP address** | Unique numerical address of a device on the internet |
| **Domain name** | Human-readable web address (e.g., google.com) |
| **Wi-Fi** | Wireless connection to the internet through a router |
| **Bandwidth** | The amount of data that can be transferred per second |

---

## 2.3 Uses of the Internet

| Use | Examples |
|-----|---------|
| **Communication** | Email, WhatsApp, social media, video calls |
| **Research and information** | Google, Wikipedia, online libraries |
| **E-commerce** | Online shopping (Jumia, Konga), banking |
| **Entertainment** | YouTube, Netflix, streaming music |
| **Education** | Online courses, e-books, distance learning |
| **Government services** | NIN registration, tax filing |
| **Social media** | Facebook, Twitter/X, Instagram, TikTok |

---

## 2.4 Email (Electronic Mail)

**Email** is a method of exchanging digital messages over the internet.

### Parts of an Email:
| Part | Description |
|------|-------------|
| **To** | Recipient's email address(es) |
| **CC** (Carbon Copy) | Other recipients who receive a visible copy |
| **BCC** (Blind Carbon Copy) | Hidden recipients — others cannot see them in the email |
| **Subject** | Brief description of the email's content |
| **Body** | The main message |
| **Attachment** | File(s) included with the email (documents, images) |

### Email Etiquette:
- Use a clear, relevant subject line
- Be polite and professional (especially in formal emails)
- Do not write in ALL CAPS (considered shouting)
- Check spelling before sending
- Do not click suspicious links (phishing risk)

---

## 2.5 Internet Safety

| Threat | Description | Protection |
|--------|-------------|-----------|
| **Virus/Malware** | Harmful software that damages or steals data | Install antivirus; avoid suspicious downloads |
| **Phishing** | Fake websites/emails that steal passwords | Check URL; never give passwords online |
| **Cyberbullying** | Harassment online | Report and block; tell a trusted adult |
| **Online predators** | Adults pretending to be young people | Never share personal info; meet no stranger |
| **Hacking** | Unauthorised access to systems | Use strong passwords; 2-factor authentication |

---

## ✏️ Worked Examples

**Example 1 (BECE type):** What is the internet? State THREE uses of the internet for students.

**Solution:**
The **internet** is a worldwide network of interconnected computers that communicate with each other using standardised protocols, allowing users to share information and resources globally.

**Three uses for students:**
1. **Research** — Students use search engines like Google to find information on any topic for assignments, projects, and general learning.
2. **Communication** — Email and messaging platforms allow students to communicate with teachers, classmates, and family members instantly.
3. **Online learning** — Educational websites, video tutorials (YouTube), and online courses provide extra study materials and explanations beyond classroom lessons.

---

## 🏆 Exam Focus

> **BECE** tests internet vs World Wide Web, email components (To/CC/BCC), internet uses, and internet safety.

> **Common trap:** The **internet** and the **World Wide Web** are NOT the same thing. The internet is the global network of connected computers. The Web is one service (websites) that runs ON the internet. Email is another internet service — it is NOT part of the Web.

# TOPIC 3: Word Processing
**Topic ID:** JSS-DGT-003-01

## 3.1 Definition

**Word processing** is the use of software to create, edit, format, save, and print text documents. The most widely used word processing software is **Microsoft Word** (also: Google Docs, LibreOffice Writer).

---

## 3.2 Basic Word Processing Operations

| Operation | How to do it |
|-----------|-------------|
| **Create a new document** | File → New (or Ctrl + N) |
| **Open a document** | File → Open (or Ctrl + O) |
| **Save a document** | File → Save (Ctrl + S); Save As (Ctrl + Shift + S) |
| **Print a document** | File → Print (Ctrl + P) |
| **Undo last action** | Ctrl + Z |
| **Redo** | Ctrl + Y |
| **Select all** | Ctrl + A |
| **Copy** | Ctrl + C |
| **Cut** | Ctrl + X |
| **Paste** | Ctrl + V |
| **Bold text** | Select text → Ctrl + B |
| **Italic text** | Select text → Ctrl + I |
| **Underline text** | Select text → Ctrl + U |
| **Find and Replace** | Ctrl + H |

---

## 3.3 Text Formatting

| Feature | Options |
|---------|---------|
| **Font type** | Times New Roman, Arial, Calibri |
| **Font size** | 12pt, 14pt, 16pt… |
| **Font style** | Bold, Italic, Underline |
| **Alignment** | Left, Centre, Right, Justify |
| **Line spacing** | Single, 1.5, Double |
| **Paragraph spacing** | Before/After paragraph spacing |
| **Bullets and numbering** | For lists |
| **Columns** | Multi-column layout (e.g., newspaper style) |

---

## 3.4 Tables and Images in Word

**Inserting a table:** Insert → Table → Select rows × columns
**Inserting an image:** Insert → Pictures → Select file

**Page setup:**
- **Margins** — Space between text and edge of page
- **Orientation** — Portrait (tall) or Landscape (wide)
- **Paper size** — A4 (most common in Nigeria), Letter

---

## ✏️ Worked Examples

**Example 1 (BECE type):** List FOUR keyboard shortcuts used in Microsoft Word and state what each does.

**Solution:**
1. **Ctrl + S** — Saves the current document without opening the Save As dialog
2. **Ctrl + B** — Makes selected text **bold**
3. **Ctrl + Z** — Undoes (reverses) the last action taken
4. **Ctrl + P** — Opens the print dialog to print the current document

---

## 🏆 Exam Focus

> **BECE** tests common keyboard shortcuts, formatting features (bold/italic/alignment), and basic page setup (margins, orientation, paper size).

> **Common trap:** **Save** (Ctrl + S) saves to the SAME file name and location. **Save As** (Ctrl + Shift + S) lets you choose a new name or location. If you want to save a copy without changing the original, always use **Save As**.

# TOPIC 4: Spreadsheets and Presentations
**Topic ID:** JSS-DGT-003-02

## 4.1 Spreadsheets (Microsoft Excel / Google Sheets)

**Spreadsheet software** is used to organise data in rows and columns, perform calculations using formulas, and create charts.

### Key Concepts:
| Term | Definition |
|------|-----------|
| **Workbook** | The entire Excel file |
| **Worksheet** | A single sheet inside the workbook (tab at the bottom) |
| **Cell** | The intersection of a row and column (e.g., A1, B5) |
| **Row** | Horizontal line of cells (numbered 1, 2, 3…) |
| **Column** | Vertical line of cells (labelled A, B, C…) |
| **Range** | A group of cells (e.g., A1:C5) |
| **Formula** | A calculation starting with = (e.g., =A1+B1) |
| **Function** | Built-in formula (e.g., =SUM(A1:A5), =AVERAGE(B2:B10)) |

---

### Common Spreadsheet Functions:
| Function | What it does | Example |
|----------|-------------|---------|
| **=SUM()** | Adds all values in a range | =SUM(A1:A5) |
| **=AVERAGE()** | Calculates the mean | =AVERAGE(B1:B10) |
| **=MAX()** | Finds the highest value | =MAX(C1:C20) |
| **=MIN()** | Finds the lowest value | =MIN(C1:C20) |
| **=COUNT()** | Counts how many numbers | =COUNT(A1:A50) |

---

## 4.2 Presentations (Microsoft PowerPoint / Google Slides)

**Presentation software** is used to create slideshows for teaching, business, or public speaking.

### Key Concepts:
| Term | Definition |
|------|-----------|
| **Slide** | A single page in the presentation |
| **Slide layout** | Pre-set arrangement of content areas on a slide |
| **Transition** | Animation effect when moving between slides |
| **Animation** | Effect applied to text or objects on a slide |
| **Slide Show** | Playing the presentation full-screen |
| **Template/Theme** | Pre-designed visual style for the presentation |

---

### Tips for Good Presentations:
- Use large, readable fonts (minimum 24pt for body text)
- Limit text per slide (the 6×6 rule: max 6 bullet points, 6 words each)
- Use high-quality, relevant images
- Use consistent colours and fonts throughout
- Do NOT put everything you want to say on the slides — slides support you

---

## ✏️ Worked Examples

**Example 1 (BECE type):** In a spreadsheet, cells A1 to A5 contain the values 10, 20, 15, 25, and 30. Write the formula to find: (a) the total, (b) the average, (c) the highest value.

**Solution:**
a) Total: **=SUM(A1:A5)** = 10 + 20 + 15 + 25 + 30 = **100**
b) Average: **=AVERAGE(A1:A5)** = 100 ÷ 5 = **20**
c) Highest value: **=MAX(A1:A5)** = **30**

---

## 🏆 Exam Focus

> **BECE** tests spreadsheet terminology (cell, row, column, formula, function), common functions (SUM, AVERAGE, MAX, MIN), and presentation software elements (slide, transition, animation).

> **Common trap:** A formula in a spreadsheet ALWAYS starts with the **= sign**. Without it, the computer treats your entry as plain text, not a calculation. =SUM(A1:A5) works; SUM(A1:A5) without the = sign does nothing.

# TOPIC 5: Algorithms and Introduction to Programming
**Topic ID:** JSS-DGT-004-01

## 5.1 What is an Algorithm?

An **algorithm** is a step-by-step set of instructions for solving a problem or completing a task. Algorithms are the foundation of all computer programs.

**Properties of a good algorithm:**
- **Clear** — Each step is unambiguous
- **Finite** — It has a definite start and end
- **Effective** — Each step is achievable
- **Correct** — It produces the correct output for all valid inputs

---

## 5.2 Ways to Represent Algorithms

### Pseudocode:
Plain language description of steps — not a real programming language but structured like one.

**Example — Algorithm to add two numbers:**
```
START
  Input first number (A)
  Input second number (B)
  Set Sum = A + B
  Display Sum
END
```

### Flowcharts:
Visual representation using standard symbols.

| Symbol | Shape | Use |
|--------|-------|-----|
| **Terminal** | Oval/Rounded rectangle | Start and End |
| **Process** | Rectangle | Actions/calculations |
| **Decision** | Diamond | Yes/No questions (if…then) |
| **Input/Output** | Parallelogram | Input data or display output |
| **Arrow/Flow line** | Arrow | Direction of flow |

---

## 5.3 Introduction to Programming

**Programming** is writing instructions in a language the computer can understand to perform a specific task.

**Programming languages:**
| Language | Main use | Difficulty |
|----------|---------|-----------|
| **Scratch** | Visual; block-based; for beginners (JSS level) | Easiest |
| **Python** | General purpose; data science; web | Beginner-friendly |
| **JavaScript** | Web development | Intermediate |
| **Java** | Android apps; enterprise | Advanced |
| **C/C++** | System software, games | Advanced |

---

## 5.4 Key Programming Concepts

| Concept | Definition | Example (Python) |
|---------|-----------|-----------------|
| **Variable** | A named storage location for a value | name = "Isaac" |
| **Input** | Getting data from the user | age = input("Enter age:") |
| **Output** | Displaying results | print("Hello World") |
| **Sequence** | Instructions executed in order | Step 1, Step 2, Step 3 |
| **Selection (if/else)** | Decision; do this OR that | if score >= 50: print("Pass") |
| **Iteration (loop)** | Repeat instructions | for i in range(5): print(i) |

---

## 5.5 Computational Thinking

**Computational thinking** is a problem-solving approach that involves:

| Component | Description |
|-----------|-------------|
| **Decomposition** | Break a big problem into smaller, manageable parts |
| **Pattern recognition** | Find similarities or trends in problems |
| **Abstraction** | Focus on the important details; ignore the rest |
| **Algorithm design** | Create step-by-step solutions |

---

## ✏️ Worked Examples

**Example 1 (BECE type):** Write an algorithm (using pseudocode) to find the larger of two numbers entered by a user.

**Solution:**
```
START
  Input first number (A)
  Input second number (B)
  IF A > B THEN
    Display "A is the larger number"
  ELSE IF B > A THEN
    Display "B is the larger number"
  ELSE
    Display "Both numbers are equal"
  END IF
END
```

**Step-by-step explanation:**
1. The algorithm starts and asks the user to input two numbers, A and B.
2. It then checks: If A is greater than B, it displays that A is larger.
3. If B is greater than A, it displays that B is larger.
4. If neither condition is true (i.e., A equals B), it displays that both are equal.
5. The algorithm ends.

---

## 🏆 Exam Focus

> **BECE** tests the definition of an algorithm, flowchart symbols, pseudocode writing, and the four components of computational thinking.

> **Common trap:** An algorithm is NOT the same as a program. An **algorithm** is the PLAN (the logical steps in plain language or a diagram). A **program** is the algorithm written in a specific programming language (Python, Java, etc.) that a computer can actually run.
