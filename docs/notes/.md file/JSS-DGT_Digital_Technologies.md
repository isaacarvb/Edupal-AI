## Introduction to Computing

### Computer Fundamentals — History, Types and Components
**Class:** JSS1  |  **Topic ID:** `JSS-DGT-001-01`

#### 🎯 Learning Objectives
- Define a computer and explain its main functions
- Trace the historical development of computers through the generations
- Classify computers by size/purpose and by mode of operation
- Identify and describe hardware components of a computer
- Distinguish between system software and application software

#### 📖 Notes
- Computer: an electronic device that accepts input data, processes it according to instructions (program), stores results, and outputs information
- Computer characteristics: speed (billions of operations/second), accuracy (if input is correct, output is correct), reliability (consistent), storage (large memory), diligence (works tirelessly)
- Generations of computers: 1st (vacuum tubes — ENIAC 1946), 2nd (transistors — 1950s–60s), 3rd (integrated circuits — 1960s–70s), 4th (microprocessors — 1971–present), 5th (AI and parallel processing — emerging)
- Classification by size: supercomputer (weather forecasting, nuclear simulations), mainframe (banks, airlines), minicomputer (medium businesses), microcomputer/personal computer (desktop, laptop, tablet, smartphone)
- Classification by purpose: general purpose (performs many tasks) vs. special purpose (one specific task — ATM, car engine controller)
- Classification by operation: digital (processes binary data — 0s and 1s), analog (processes continuous signals — thermometer), hybrid (both)
- Hardware: physical components; input devices (keyboard, mouse, microphone, scanner, webcam, joystick), output devices (monitor, printer, speaker, projector), storage devices (HDD, SSD, USB drive, DVD), processing unit (CPU)
- CPU (Central Processing Unit): brain of the computer; Arithmetic Logic Unit (ALU — calculations), Control Unit (CU — manages operations), Registers (temporary storage)
- Memory: RAM (Random Access Memory — volatile, temporary, working memory), ROM (Read-Only Memory — non-volatile, stores BIOS/firmware)
- System software: operates and manages computer hardware; Operating System (Windows, MacOS, Linux, Android, iOS)
- Application software: performs specific tasks for users; word processor, spreadsheet, web browser, games, educational software
- GIGO: Garbage In, Garbage Out — quality of output depends on quality of input

#### ✏️ Activities
1. Label a diagram of a desktop computer: monitor, keyboard, mouse, CPU tower, speakers, printer; classify each as input or output or processing
2. Create a generations timeline: draw computer shapes for each generation with the technology used and an example from Nigeria's context
3. Classify 10 software programs as system or application: Windows 10, MS Word, Chrome browser, Android, Photoshop, Ubuntu, WhatsApp, antivirus software

#### 🏆 Exam Focus
> BECE tests computer definition, classification by size/purpose/operation, input/output device identification, and RAM vs. ROM difference
> Know: RAM is temporary (lost when power off); ROM is permanent (BIOS stored there); Hard disk is secondary storage (not RAM)
> Trap: the keyboard is an INPUT device and the monitor is an OUTPUT device — students sometimes reverse these; a printer is output, not input

## Internet and Digital Communication

### Internet, Email, Social Media and Digital Safety
**Class:** JSS2  |  **Topic ID:** `JSS-DGT-002-01`

#### 🎯 Learning Objectives
- Explain how the internet works and identify key internet terms
- Use email effectively for communication
- Identify the benefits and risks of social media
- Apply digital safety practices to protect personal information
- Describe cyberbullying and explain how to respond to it

#### 📖 Notes
- Internet: global network of computers connected to share information using TCP/IP protocols; not owned by any single entity
- World Wide Web (WWW): collection of websites and web pages accessible via the internet; invented by Tim Berners-Lee (1991)
- Key internet terms: URL (Uniform Resource Locator — web address), HTTP/HTTPS (protocol for web pages; S = secure), IP address (numerical label for each device), domain name (.com, .ng, .org, .edu), ISP (Internet Service Provider — MTN, Airtel, Glo, 9mobile in Nigeria)
- Email: electronic mail; send/receive messages over the internet; faster and cheaper than postal mail
- Email structure: From, To, CC (carbon copy), BCC (blind carbon copy), Subject, Body, Attachment
- Email etiquette: clear subject line, greeting, concise body, proper closing, professional language in formal email
- Social media: websites and apps for creating and sharing content and networking; Facebook, Instagram, Twitter/X, TikTok, WhatsApp, Telegram
- Benefits of social media: communication, education, business, entertainment, activism, information sharing
- Risks of social media: cyberbullying, fake news, privacy violation, addiction, screen time, exposure to inappropriate content
- Digital safety/cybersecurity: protecting personal information and devices online
- Digital safety practices: strong passwords (12+ characters, mix of letters/numbers/symbols), never share passwords, privacy settings, avoid unknown links (phishing), update software, use VPN on public WiFi
- Cyberbullying: bullying using digital technology (harassment, spreading rumours, exclusion online); effects on mental health; report to an adult/school authority/platform
- Digital footprint: trail of data left when using internet; permanent; potential employers can see it — think before posting

#### ✏️ Activities
1. Compose a formal email to a school principal requesting permission for a class excursion; apply correct email format and etiquette
2. Create a 'Digital Safety Pledge' for the class: list 5 rules everyone agrees to follow online; design as a poster for the ICT lab
3. Case study: read a scenario of cyberbullying; identify what happened, the impact on the victim, and 4 steps the victim and school should take

#### 🏆 Exam Focus
> BECE tests internet terminology (URL, HTTP, ISP, IP address), email format, social media risks, and digital safety practices
> Know: WWW ≠ Internet; internet is the global network infrastructure; WWW is the collection of websites that run ON the internet
> Trap: BCC (blind carbon copy) recipients are hidden from other recipients; CC recipients are visible to all — important for professional email

## Productivity Software

### Word Processing (Microsoft Word / Google Docs)
**Class:** JSS1  |  **Topic ID:** `JSS-DGT-003-01`

#### 🎯 Learning Objectives
- Identify the key features of a word processing application
- Create, format and save a document
- Apply text formatting (font, size, bold, italic, underline, alignment, spacing)
- Insert tables, images and headers/footers into a document
- Use spell check and grammar tools effectively

#### 📖 Notes
- Word processor: software for creating, editing, formatting and printing text documents; examples — Microsoft Word, Google Docs, LibreOffice Writer
- Word processor interface: title bar, menu bar/ribbon (Home, Insert, Layout, Review, View), document area, status bar, scroll bar
- Creating a document: File → New; name and save: File → Save As (choose folder and file name); save regularly (Ctrl+S)
- Font formatting: font type (Arial, Times New Roman, Calibri), font size (measured in points), font style (bold — Ctrl+B, italic — Ctrl+I, underline — Ctrl+U)
- Paragraph alignment: Left (Ctrl+L), Center (Ctrl+E), Right (Ctrl+R), Justify (Ctrl+J)
- Line spacing: single, 1.5, double; paragraph spacing (before/after)
- Page layout: margins, orientation (portrait/landscape), paper size (A4 most common)
- Inserting objects: table (rows and columns for organizing data), image/picture (Insert → Picture), shapes, headers and footers
- Header: text appearing at top of every page (e.g. document title); footer: at bottom (e.g. page number)
- Cut (Ctrl+X), Copy (Ctrl+C), Paste (Ctrl+V): for moving/duplicating text
- Find and Replace (Ctrl+H): replaces specific text throughout document
- Spell check and grammar: red wavy underline = spelling error; green = grammar error; right-click for suggestions

#### ✏️ Activities
1. Type a 200-word personal essay about yourself in Word/Google Docs; format with 12pt Times New Roman, double spacing, justified alignment, your name as a header
2. Create a 3-column, 5-row table in Word listing 5 Nigerian states: state name, capital city, major language
3. Find and replace all occurrences of 'colour' with 'color' in a document; discuss when this might be useful

#### 🏆 Exam Focus
> BECE tests word processor interface components, keyboard shortcuts (Ctrl+S = save, Ctrl+B = bold, Ctrl+Z = undo), formatting options, and difference between cut and copy
> Know all basic shortcuts: Ctrl+C (copy), Ctrl+X (cut), Ctrl+V (paste), Ctrl+Z (undo), Ctrl+Y (redo), Ctrl+A (select all)
> Trap: saving (Ctrl+S) saves to the same location with the same name; Save As (Ctrl+Shift+S or F12) lets you choose new name/location — use Save As for a new document

### Spreadsheets (Microsoft Excel / Google Sheets) and Presentations
**Class:** JSS2  |  **Topic ID:** `JSS-DGT-003-02`

#### 🎯 Learning Objectives
- Explain the purpose of a spreadsheet application
- Enter data and simple formulas into a spreadsheet
- Create a basic chart from spreadsheet data
- Describe the key features of presentation software
- Create a simple presentation with multiple slides

#### 📖 Notes
- Spreadsheet: software for organising, analysing and visualising data in rows and columns; examples — Microsoft Excel, Google Sheets
- Spreadsheet interface: cells (intersection of row and column — named by column letter + row number, e.g. A1), rows (horizontal, numbered), columns (vertical, lettered), worksheets (tabs at bottom), workbook (whole file)
- Entering data: click cell → type → press Enter (moves down) or Tab (moves right)
- Cell references: relative (A1 — changes when copied), absolute ($A$1 — stays fixed when copied)
- Formulas: begin with = sign; e.g. =A1+A2, =SUM(A1:A10), =AVERAGE(B2:B6), =MAX(C1:C5), =MIN(C1:C5), =COUNT(D1:D10)
- Formatting: number formats (currency ₦, percentage %, date), bold/colour for headers, borders
- Charts: select data → Insert → Chart; types — column/bar (comparing categories), line (trends over time), pie (parts of whole)
- Presentation software: for creating slideshows; Microsoft PowerPoint, Google Slides, Canva
- PowerPoint interface: slide panel (left), slide area (centre), notes panel (bottom), ribbon
- Slide layout: title slide, content slide, two-content, blank; choose appropriate layout
- Animations and transitions: use sparingly; avoid distraction; must serve the presentation
- Design principles for presentations: max 6 words per line, max 6 lines per slide, large readable font (24pt minimum), consistent theme, relevant visuals

#### ✏️ Activities
1. Create a spreadsheet of 10 students' test scores in 3 subjects; use SUM and AVERAGE formulas to calculate totals and averages; rank the students
2. Build a bar chart from the test score spreadsheet; give it a title, label the axes, and choose appropriate colours
3. Create a 5-slide PowerPoint presentation on 'Water pollution in Nigeria' — include a title slide, 3 content slides (causes, effects, solutions) and a conclusion

#### 🏆 Exam Focus
> BECE tests spreadsheet terminology (cell, row, column, formula), basic functions (SUM, AVERAGE), chart type selection, and presentation design principles
> Always start a formula with = in Excel/Sheets; =SUM(A1:A5) adds cells A1 through A5
> Trap: cell A1 is column A, row 1 — NOT row A, column 1; remember columns are LETTERS (vertical), rows are NUMBERS (horizontal)

## Algorithms and Digital Thinking

### Problem Solving, Algorithms and Introduction to Programming
**Class:** JSS3  |  **Topic ID:** `JSS-DGT-004-01`

#### 🎯 Learning Objectives
- Explain what an algorithm is and write simple algorithms
- Represent algorithms using flowcharts and pseudocode
- Identify input, process and output in a computational problem
- Write and run simple code in Scratch or Python
- Apply computational thinking (decomposition, pattern recognition, abstraction, algorithms) to solve problems

#### 📖 Notes
- Algorithm: a step-by-step set of instructions for solving a problem; must be clear, finite, and produce a correct result
- Characteristics of a good algorithm: clear (unambiguous), ordered (correct sequence), finite (has an endpoint), effective (achieves goal)
- Example algorithm — making a phone call: Pick up phone → Unlock screen → Open contacts or dial pad → Enter number → Press call → Wait for response → Speak → End call
- Flowchart symbols: Oval/rounded rectangle (Start/End — terminal), Rectangle (Process/action), Diamond (Decision — Yes/No branches), Parallelogram (Input/Output), Arrow (Flow direction)
- Pseudocode: structured English-like language describing an algorithm; not real code; readable by humans
- Computational thinking components: Decomposition (break problem into smaller parts), Pattern recognition (identify similarities), Abstraction (focus on essential details, ignore irrelevant), Algorithms (step-by-step solution)
- Programming: writing instructions for a computer in a programming language
- Scratch (MIT): visual block-based programming; good for beginners; drag and drop code blocks; animations, games, stories
- Python (basic): text-based language; print() to output; input() to get data; variables to store data; if/else for decisions; for/while loops
- Basic Python: print('Hello, World!'); name = input('Enter your name: '); print('Hello, ' + name)
- Variables: named storage locations for data; in Python: age = 15; name = 'Fatima'; score = 95.5
- Conditional statements (if/else): make decisions; if score >= 50: print('Pass') else: print('Fail')
- Loops: repeat actions; for i in range(5): print(i) — prints 0, 1, 2, 3, 4

#### ✏️ Activities
1. Write an algorithm and draw a flowchart for: 'A student wants to determine whether they have passed or failed their exam (pass mark = 50)'
2. Create a Scratch animation: a cat that moves across the screen, changes colour when clicked, and says 'Hello!' when it reaches the edge
3. Write a Python program that asks a user for their name and age, then prints a personalised message: 'Hello [name], you are [age] years old'

#### 🏆 Exam Focus
> BECE tests flowchart symbols (oval, rectangle, diamond, parallelogram), algorithm writing, and computational thinking terminology
> Know all four flowchart shapes and what each represents — a diagram question WILL appear in BECE
> Trap: the diamond in a flowchart represents a DECISION (Yes/No question) — it does NOT represent a process; a rectangle is for processes
